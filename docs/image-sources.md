# Изображения: источники и права

Все файлы локальные (`public/images/**`). Внешних `pinimg`/`unsplash` URL в коде нет.
Кадры найдены через Pinterest-поиск, скачаны в `pinterest-refs/` (вне репозитория) и приведены
к системе: дуотон `ink → plum → тёплая sand → milk`, кроп под сетку, WebP.

> **Права не подтверждены.** Pinterest — это ссылки на чужие работы, а не лицензия.
> В колонке «Автор» указан аккаунт, сохранивший пин, — это **не обязательно фотограф**.
> Перед коммерческим запуском каждый кадр нужно заменить собственной съёмкой,
> купленной лицензией или рендером. См. отчёт агента.

API поиска не отдаёт короткую ссылку на пин. Ниже — прямая ссылка на файл, аккаунт,
доска и дата сохранения пина: по `image_url` пин находится через поиск Pinterest.

## Обработка

Градиентная карта, не фильтр поверх фото: каждый кадр переведён в яркость, прогнан через
кривую (`gamma`/`gain` подбирались индивидуально под контраст исходника) и раскрашен по пяти стопам:
`#0B0809 → #1E151C → #563C34 → #C69E80 → #F6ECE2`. Дальше — WebP (q66–78), без апскейла.
Зерно и волосяная рамка добавляются в вёрстке (`.plate-kind`), не в файле.

Для секции 05: `gamma 0.9`, `lift +0.05`, `contrast 1.05`, WebP q82. Фрагменты не апскейлились
больше 1,3× (`skin-macro` — из кропа 600 px, `light-macro` — из 640 px). Фрагмент вырезан
по ключевой точке кадра (глаз, блик) и выровнен по высоте с кадром: на значении 50 граница
проходит по одной и той же части лица, поэтому читается как край лупы, а не как склейка.
